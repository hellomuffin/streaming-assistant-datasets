Streaming guidance dialogue —

What GuideMe tests. A user performs a multi-step task (cooking, daily-life routine, fitness workout, object manipulation) and asks once, at the start, to be guided. The video then streams. At each queried time the model sees the last 60 s of video plus the dialogue so far and must either answer Silent or speak one of four outputs: a next-step instruction, completion feedback (the step was done right), error detection (a mistake just happened), or corrective guidance (how to fix it). The reference dialogue is written by an LLM from the source datasets' step/error annotations, placed at action start (instruction) and action end (feedback or error + correction). Default evaluation is anchor-based: every reference assistant timestamp is a speak query, plus an equal number of silent queries at least 5 s from any anchor (hatched on the timeline); predictions are scored as correct-silent / false-alarm / no-response / partly-correct and by time-decayed semantic matching.

Fields. Each record has video_id, videos (file in videos_2fps/) and conversations: turns with from (user | assistant), value (text) and timestamp (integer seconds in the source video). The release has no output-type field: the type pills below are this viewer's hand labels (_viewer_output_types); a keyword heuristic used for the preview-wide stats is shown underneath only where it disagrees.
