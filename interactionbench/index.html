How an item is scored

    
Metric and evaluation rules (from the InteractionBench README and GitHub repository)
    

      
The system watches the stream and decides at every moment whether to speak. Each item is scored on three things, each on a 0–100 scale.

      
    
        
  1. Accuracy: is the content right. Multiple-choice items are scored by option match. Free-form content is scored by a judge; the paper uses Qwen/Qwen3-14B.
    2. 
        
  2. Timing Accuracy (TA) = 100/N · Σn max(0, 1 − dn/Δ). Here dn is the delay of the response matched to ground-truth event n, and Δ = 5 s. An unanswered event scores 0. In the timeline below, the shaded span after each green mark is this 5-second credit window.
    3. 
        
  3. Silence Compliance (SC) = 100 · max(0, 1 − |V| / max(N,1)). V counts premature, redundant and spurious responses.
    4. 
        
  4. Total = mean(Accuracy, harmonic_mean(TA, SC)). Commentate items use Accuracy alone. Items that require silence use SC alone.
    5. 
        
  5. Valid runs: the system must not see frames later than its decision time; an A question must not be shown before question_time_s; the answer key must not be shown to the system.
    6. 
        
  6. Protocols for turn-based models: sliding (the last N frames, each poll a new conversation), cumulative (all frames so far, subsampled), interleaved (one growing conversation with its own earlier replies), and offline (whole video in one call, reference only).
    7. 
        
  7. Near-miss suites (53 items): verified distractor moments that look like the event but are not. They feed an analysis script, not the main score. Where an item has one, it is drawn on the timeline in orange.
